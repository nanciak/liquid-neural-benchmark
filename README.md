# Liquid Neural Benchmark

A unified benchmark for comparing Liquid Neural Networks
(CfC and LTC) with traditional sequence models.

## Objectives

- Fair comparison across datasets
- Fully reproducible experiments
- Noise robustness evaluation
- Sampling-rate robustness
- Distribution-shift robustness
- Statistical significance testing
- Explainability analysis

## Models

- CfC
- LTC
- LSTM
- GRU
- CNN
- TCN
- Transformer

## Datasets

- Event MNIST
- PhysioNet 2012
- PAMAP2
- UCI HAR
- Solar Forecasting
